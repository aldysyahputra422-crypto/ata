# Tanya Ata (kelompok 3) Implementation Plan

> Dijalankan native (superpowers:executing-plans). Ledger: `.superpowers/sdd/2026-11-13-tanya-ata/progress.md`.

**Goal:** Prototipe Tanya Ata: Chat dengan kartu aksi, Resep jalur pipa AI, Ingatan papan kartu.
**Architecture:** `tanya.html` di akar `ata-prototype/`, modul di `tanya/` (data, logic, ui), fondasi `shared/`, logika murni diuji `node --test`.
**Spec:** `/Users/mac/ata/docs/superpowers/specs/2026-11-13-tanya-ata-design.md`

## Global Constraints
Sama dengan kelompok 1–2 (palet Senja, Bahasa Indonesia, DATA DEMO, maskot resmi tanpa diubah, memuat/kosong/galat, 375 dan 1280 px, terang dan gelap, reduced motion, target 44 px).

## Review Focus
- Saklar privasi dimatikan → bidang itu tidak ada di teks yang disalin (termasuk di langkah berikutnya).
- Variabel tak dikenal atau hasil langkah sebelumnya kosong → kolom isian, bukan `{{…}}` mentah atau galat.
- Tempel lebih dari 12.000 karakter → pesan jelas, teks tidak hilang.
- Hapus/Lupakan semua Ingatan → tidak lagi muncul di baris konteks "Ata pakai".
- Teks berisi nomor kartu atau kata sandi → tidak masuk usulan Ingatan.

### Task 1: Data dan logika (TDD)
`tanya/data/{resep,ingatan,profil}.js`; `tanya/logic/templat.js` (`isiTemplat(teks, konteks, {mati}) -> {teks, kosong[]}`), `resep.js` (`resepUntuk(jenis)`, `duplikat(resep)`, `keMarkdown(racikan)`), `konteks.js` (`pilihIngatan(list, 12)`, `paketKonteks(...)`), `ingatan.js` (`saringSensitif(teks)`), `jawab.js` (`jawabDemo(pesan, konteks)`). Tes: `tests/{templat,resep-ata,konteks,ingatan-ata,jawab}.test.mjs` termasuk lima baris Review Focus.

### Task 2: Halaman dan Chat
`tanya.html`, `tanya/app.js`, `tanya/state.js`, `tanya/ui/chat.js`, `tanya/tanya.css`: thread, baris konteks, chip, streaming simulasi, kartu aksi, Mode Tanpa Key, galat, Ingat ini.

### Task 3: Resep dan stepper
`tanya/ui/resep.js`, `jalan.js`: pustaka, Punyaku, jalur pipa, pratinjau privasi, salin/tempel, aliran hasil, Racikan, ekspor Markdown.

### Task 4: Ingatan
`tanya/ui/ingatan.js`: papan per jenis, sematkan, sunting, hapus dengan urungkan, Lupakan semua, Ingat otomatis.

### Task 5: Uji browser, review akhir, terbit
HP dan desktop, terang dan gelap; peninjau independen (opus); terbitkan `tanya.html`; perbarui beranda dan `docs/STATUS.md`.
